  ADDING MORE TRACKS

  1. Drop the file in  assets/music/
  2. Open  js/music.js  and add an entry to TRACKS:

       mytrack: {
         file: 'assets/music/mytrack.mp3',
         title: 'Track Name',
         composer: 'Composer Name',
         licence: 'CC BY 4.0',
         licenceUrl: 'https://creativecommons.org/licenses/by/4.0/',
         source: 'https://...',
         loop: true,
         gain: 0.85          // per-track level trim
       }

  3. Assign it to a screen in SCREEN_MUSIC:

       menu:     'mytrack',
       tactical: 'somethingQuieter',

  Missing files fail silently - the game will not crash if a
  track is absent, and a failed track is automatically left
  out of the credits screen.
